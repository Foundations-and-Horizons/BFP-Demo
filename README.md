# Bountiful Food Pantry — operations demonstration

**Demo:** https://foundations-and-horizons.github.io/BFP-Demo/

This is a public, fictional, browser-local prototype for Bountiful Food Pantry staff discovery and review. It is **not** a production system, secure shared database, official report source, or integration with PantrySoft, MealConnect, financial services, or BFP volunteer systems. Do not enter real client, donor, volunteer, or confidential information.

## Recommended staff walkthrough

1. **Daily Work:** Start with staff tasks; switch to container requests, review feedback, or the walkthrough checklist. Each workspace is a separate tab.
2. **Market:** Review duplicated and unduplicated household counts, person-visits, pounds-per-visit measures, and outstanding source definitions.
3. **Off-site Services:** Compare Mobile Truck/Bus stops and visits. Truck runs have separate load/return/transfer/disposal weights. Bus pounds are not inferred.
4. **Incoming / Outgoing Food:** Use the section buttons to switch between daily entries, donor reporting, food drives, and acknowledgement preparation. The selected section persists across updates.
5. **Grocery Rescue and Inventory:** Review source separation, warehouse movement exceptions, physical counts, and printable count sheet. Official seven categories and food-bank transfer forms await staff materials.
6. **Pantry Packs, Community Engagement, Grants and Monthly Financials:** Review the prototype reporting fields and note missing source information.
7. **Board Reporting:** Select dates and location, edit the narrative, preview the draft report, and use Print / Save PDF. Check source-readiness notes before sharing any figures.

## Demo data and limitations

- Records and edits are stored in the **current browser**. Other staff devices do not see them.
- The Reset demo data button restores fictional seed data. Browser storage clearing may erase locally entered tasks, review notes, and request records.
- Export available CSVs before clearing browser data. Do not treat exports as audited reports.
- Northern Davis is a planned location, not an active data source.
- Monthly imported aggregate values, financial summaries, physical counts and service-visit records have different origins; missing figures must not be treated as zero.
- Volunteer PIN experiences and local records do not provide production authentication.
- Production needs BFP-owned hosting and database, secure staff roles, verified data migration, backups, and a reviewed audit/approval model.
